# homebrew-betterlanscan

Homebrew tap for [BetterLanScan](https://github.com/DewanPieterse/BetterLanScan) —
a native macOS network & Wi-Fi scanner.

```bash
brew install --cask dewanpieterse/betterlanscan/betterlanscan
```

The app is ad-hoc signed (not notarized). On first launch macOS shows an
"unidentified developer" prompt — right-click the app ▸ Open, or use:

```bash
brew install --cask --no-quarantine dewanpieterse/betterlanscan/betterlanscan
```
